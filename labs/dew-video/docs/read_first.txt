Open the lab manual in LAB DOCS.

If this lab was just copied to a new VM, start it from the repository root with only these two commands:

git pull
bash start-dew-lab.sh dew-video

The script syncs the lab, builds missing local Docker images, clears stale DEW containers/networks, and starts Labtainer. Use LABTAINER_STUDENT_DIR=/path/to/labtainer-student if Labtainer is installed in a custom location.

You will use the dew-video machine to embed and extract a video watermark using simplified Differential Energy Watermarking (DEW). Then you will copy the watermarked video to the tester machine for validation and re-encoding tests.
