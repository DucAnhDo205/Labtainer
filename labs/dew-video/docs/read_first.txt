Open the lab manual in LAB DOCS.

If this lab was just copied to a new VM, first build the local images:

cd ~/labtainer/labtainer-student
rebuild -L -f -b dew-video
labtainer -r dew-video

Use ~/labtainer/trunk/scripts/labtainer-student and ./bin/rebuild if your installation uses the trunk directory.

You will use the dew-video machine to embed and extract a video watermark using simplified Differential Energy Watermarking (DEW). Then you will copy the watermarked video to the tester machine for validation and re-encoding tests.
