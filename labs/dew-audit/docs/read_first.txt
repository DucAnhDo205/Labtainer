Open the lab manual in LAB DOCS.

If this lab was just copied to a new VM, first build the local images:

cd ~/labtainer/labtainer-student
rebuild -L -f -b dew-audit
labtainer -r dew-audit

Use ~/labtainer/trunk/scripts/labtainer-student and ./bin/rebuild if your installation uses the trunk directory.

You will use the audit machine to mark a synthetic audit video using simplified Differential Energy Watermarking (DEW). Then you will copy the watermarked video to the verifier machine for validation and compression-like attack tests.
